# Обработка этикеток

Скрипт для автоматической обработки этикеток из сетевых каталогов. Извлекает артикулы из имен файлов, определяет пиктограммы и извлекает текстовую информацию с этикеток.

## Установка

1. Установите Python 3.8 или выше

2. Установите Tesseract OCR:
   - Windows: Скачайте установщик с https://github.com/UB-Mannheim/tesseract/wiki
   - После установки добавьте путь к Tesseract в PATH или укажите путь в скрипте:
     ```python
     pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
     ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

Запустите скрипт:
```bash
python process_labels.py
```

Скрипт:
- Сканирует указанные каталоги с этикетками
- Извлекает артикулы из имен файлов
- Определяет пиктограммы на этикетках
- Извлекает текст с помощью OCR
- Создает Excel файл `этикетки_анализ.xlsx` с результатами

## Настройка

В файле `process_labels.py` можно изменить:
- Пути к каталогам в переменной `CATALOGS`
- Список пиктограмм для поиска в словаре `PICTOGRAMS`
- Паттерн для извлечения артикулов в `ARTICLE_PATTERN`

## Структура выходного Excel файла

- **Артикул** - извлеченный артикул из имени файла
- **Файл** - имя файла этикетки
- **Путь** - полный путь к файлу
- **Пиктограммы** - список найденных пиктограмм
- **Текст** - извлеченный текст с этикетки
- **Пиктограмма_*** - отдельные колонки для каждой пиктограммы (Да/Нет)
